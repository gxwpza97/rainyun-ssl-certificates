## 免费证书怎么申请：自动验证和手动验证差在哪

雨云证书中心申请免费证书时，验证方式分两种，取决于你的域名放在哪。

域名在雨云注册、并且用的是雨云默认 DNS 服务器，申请页会出现自动验证选项。系统替你往解析里加记录，不用打开 DNS 后台复制粘贴，3 分钟内签发完成。这是雨云这套流程里最省事的一环，也是很多人选它的原因。

域名不在雨云，或者注册在雨云但换过 DNS 服务器（比如改到了第三方解析），自动验证用不了，只能走手动 DNS 验证：按页面提示自己加一条解析记录，等生效后回来确认。解析多久生效，出证就多久，没有固定时长。

申请记录会留在列表里，7 天内的申请可以发起重新验证，手动 DNS 验证的也一样。这条对卡在验证环节的人有用：解析填错了或者加晚了，不用删掉重来。

## 90 天到期，一年要处理四次

Let's Encrypt 免费证书有效期 90 天，一年摊下来大约 4 次续期。每次续期都是一轮验证：自动验证的域名点几下就过去，手动验证的要重新回 DNS 后台加记录。

免费证书的钱是 0，花的是时间。一个站一年四次，每次十分钟；十个站就是四十次。站点少、域名都在雨云、走自动验证的话，这点操作基本可以忽略；站点多、域名散在不同注册商，续期就会变成一件容易忘、忘了就出事的事。

这也是付费证书真正的卖点之一。付费档位按年订阅，续期频率低，不用每季度盯一次到期日。

## 买了 1 年，为什么中途还要换一次证

SSL 证书有两个有效期，容易混。**订阅有效期**是从首次签发日算起的订单时长，买一年就是一年。**签发有效期**是 CA 实际签发那张证书的信任窗口，到期后信任链断裂，浏览器直接报错，网站打不开。

CA/B 论坛对单张证书的签发有效期设了上限，所以 1 年订阅期内通常要在中途重新签发一次新证书并部署上去，订阅到期日不变。1 年期买到的是这一年的签发额度和管理服务，不是一张能用满 365 天的文件。

这点对做预算有用：付费证书省掉的是 90 天一轮的频繁操作、更低的续期频率，以及 OV/EV 的验证等级，不是“部署一次管一年”。

## 三条写在细则里的限制

**下单后不能改域名。** SSL 证书绑定的是域名，订单提交之后域名信息不可修改，买错只能重新申请一次。下单前把要保护的域名列出来对一遍，尤其是多域名套餐，写错一个就得整单重来。

**多域名证书不含通配符。** 多域名证书保护的是几个明确写出来的域名，不能在一张证书里同时塞 `example.com` 和 `*.example.com`。主域名和一堆子域名要一起覆盖，选通配符；几个互不相关的独立域名，选多域名。

**免费和付费的验证等级不同。** 免费证书和 DV 付费证书都只验证域名所有权，差别在订阅期和续期频率。OV 要核验企业主体信息，EV 审核最严、要交的材料最多。浏览器地址栏现在统一显示锁图标，OV/EV 的差别体现在点开锁看到的证书详情里，那里会显示企业名称。需要向访客证明“这个站是某某公司在运营”，才有必要上 OV 或 EV。

签发时间上，DV 通常几分钟到一刻钟；OV/EV 要人工核验企业资料，按行业惯例大约 5 个自然日，材料齐不齐影响进度。

## 证书中心能省掉的事

证书在雨云证书中心上传一次，虚拟主机、CDN 这些用到证书的地方可以直接选，并且支持一键替换。证书到期换了新的，在中心更新一次，绑定的地方跟着变，不用挨个进去改。

签发后能导出 Nginx、Apache、Tomcat、IIS 几种常见格式，拿到服务器上直接用。

这两条对同时管几个站的人有实际价值，只跑一个站的用户感知不强。

## 什么情况下不该买付费证书

一个域名、个人博客或测试站、能接受 90 天续一次，用免费的就行，不必买 149 元的 DV。DV 付费买到的主要是一年订阅期和更少的续期次数，验证等级和免费证书一样，都是只验域名所有权。

值得掏钱的场景有这么几个：要给客户看的正式站点，不想每季度盯到期日；主域名下子域名超过三四个，通配符能省掉逐张申请；企业对外服务需要在证书详情里展示企业名称；支付、金融类业务，对审核等级有硬要求。

## 常见问题

**域名不在雨云，能用雨云的证书吗？**
能申请，但自动验证用不了，只能手动 DNS 验证或文件验证，出证时间取决于解析生效速度。想用上自动验证，域名得在雨云注册并使用默认 DNS。

**证书能下载成什么格式？**
Nginx、Apache、Tomcat、IIS 等常见格式。

**服务器在中国大陆，还要做什么？**
ICP 备案。没备案网站打不开，证书装得再好也没用。

**中文域名能申请吗？**
可以，提交前要先转成 Punycode。

**买错了域名能改吗？**
不能，下单后域名信息不可修改，只能重新申请。

## 下单前确认两件事

第一件，域名清单。要保护几个域名，是不是都在同一个主域名下，有没有拼错的。

第二件，要不要通配符。子域名超过三四个，直接看通配符；只有一两个子域名，多域名或单域名更划算。

对着清单走一遍判断：单域名 + 能接受 90 天续期 → 免费证书；多个子域名 → 通配符 DV；企业对外服务 → OV；支付金融 → EV。付费档位记得在结算页核对一遍实际金额再付款。
